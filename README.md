# BookMatch
Project description: A book recommendation system that matches users with ideal books based on their age group, genre preferences, and language

How to run the code: 
1. Install de PANDAS library.
2. Download book.csv and bookmatch.py in the same folder.
3. Now you can hit start.

Implemented features:
When you hit start, 4 options will appear:
1- will show you recomendations
2- will show you the book search history
3- will show you what is most popular with statistics
4- it will close the program 

A brief explanation of how the implemented features begin to address the identified problem or need: 
It gives people an easier way to find books they may find interesting, allowing them to select their preferences. Filtering books into one option depending on what you previously selected.
